Penyesuaian Flatpickr (Catatan Teknis)

Desain-desain di atas dirancang untuk bisa menimpa (override) struktur CSS bawaan milik plugin Flatpickr.
Nantinya, kita akan mengubah class .theme-modern-glow di blok CSS global kita untuk memaksa Flatpickr merender strukturnya menyerupai salah satu opsi di atas.
